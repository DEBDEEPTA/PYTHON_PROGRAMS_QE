
## DefaultDict
    It automatically provides a default value for a key that does not exist, instead of raising a KeyError
| Factory | Default Value | Use Case              |
| ------- | ------------- | --------------------- |
| `int`   | `0`           | Counting              |
| `float` | `0.0`         | Numerical aggregation |
| `list`  | `[]`          | Grouping              |
| `set`   | `set()`       | Unique collections    |
| `dict`  | `{}`          | Nested dictionaries   |
